## Quick Start

### 1. Install npm Dependencies

```bash
cd frontend
npm install
# or
pnpm install
# or
yarn install
```

This installs:
- `next` 16.3.5 — React framework (App Router)
- `react` 19.2.8 + `react-dom` 19.2.8
- `@tailwindcss/postcss` ^4 — Tailwind CSS v4
- `typescript` ^5
- `@biomejs/biome` 2.4.2 — lint + format (replaces eslint + prettier)
- `@types/node`, `@types/react`, `@types/react-dom`

### 2. Verify Tailwind CSS Configuration

`tailwind.config.js` should be auto-generated by `tailwindcss v4` with sensible defaults for the project. Key settings typically include:

- `content: ["./app/**/*.{js,ts,jsx,tsx}", "./components/**/*.{js,ts,jsx,tsx}"]`
- `theme: { extend: { colors: { zinc: ... }, foreground: ... } }`
- `plugins: []`

If `tailwind.config.js` doesn't exist yet, run:

```bash
npx tailwindcss init -p
```

Then verify `postcss.config.mjs` references `tailwindcss`:

```js
// postcss.config.mjs
import tailwindcss from "@tailwindcss/postcss";
export default {
  plugins: [tailwindcss],
};
```

### 3. Start the Development Server

```bash
npm run dev
# or
pnpm dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The homepage (`app/page.tsx`) will show. From there you can navigate to:

- `/stations` — Station list with health labels (Healthy/Degrading/Faulty)
- `/stations/BOMBAY001` — Station detail with charts + latest reading
- `/alerts` — Live anomaly alert feed (WebSocket driven)
- `/alert/1` — Alert detail with SHAP explanation

### 5. Linting & Formatting

```bash
# Check for issues (exit 0 = clean)
npm run lint

# Auto-fix formatable issues
npm run format
```

Biome config (`biome.json`) handles:
- TypeScript/JS lint rules
- Import sorting
- Code style (semi, quotes, indentation)
- Tailwind CSS class ordering (recommended)

### 6. Project Conventions

- **App Router**: All new pages go under `app/` directory (Next.js 16 App Router)
- **File-based routing**: `app/foo/bar.tsx` → `/foo/bar`
- **Tailwind CSS v4**: Utility-first styling; no custom CSS needed for standard UI
- **TypeScript strict**: `tsconfig.json` has `"strict": true`
- **Component naming**: PascalCase for components (`HealthBadge.tsx`), camelCase for props
- **WebSocket integration**: Use SWR or custom hook for `/ws/alerts` + `/ws/health` channels
- **Shadcn/ui patterns**: If adding shadcn components later, follow the existing design system

### 7. WebSocket Integration (Prototype)

The frontend connects to the backend WebSocket at `ws://localhost:8000/ws/alerts`:

```tsx
// Example: useWebSocketAlerts hook (to be created in components/)
function useWebSocketAlerts() {
  const [alerts, setAlerts] = useState([]);
  const ws = new WebSocket("ws://localhost:8000/ws/alerts");

  ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    setAlerts(prev => [...prev, data]);
  };

  return alerts;
}
```

Alert data shape (per TRD §3.8 API Contract):
```json
{
  "station_id": "BOMBAY001",
  "ts": "2024-06-15T14:30:00Z",
  "anomaly_type": "spike",
  "confidence": 0.87,
  "severity": "high",
  "shap_summary": {"temperature": 0.62, "pressure": 0.28, "humidity": 0.10},
  "root_cause_tag": "spike_temperature"
}
```

### 8. Adding a New Page

```bash
# Example: add station detail page
mkdir -p app/stations/[id]
# Create app/stations/[id]/page.tsx
```

Next.js App Router will automatically map `/stations/BOMBAY001` to this route.

### 9. Deployment

```bash
npm run build     # next build
npm run start     # next start
```

For Docker deployment, see the backend README section on `docker-compose` — the frontend Dockerfile uses `nginx` or `next start` to serve the built app.

## Notes

- The homepage (`app/page.tsx`) is a starter screen — replace/edit it as you build out the dashboard.
- Tailwind CSS v4 config is intentionally minimal; extend `tailwind.config.js` or `postcss.config.mjs` as needed for custom colors/fonts.
- All paths `@/...` in `tsconfig.json` resolve to `./...` (same directory), making imports straightforward.
